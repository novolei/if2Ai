# A.2 Daydream Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship background memory consolidation — opt-in idle-triggered cycle that wires the A.1 building blocks (ForgettingCurveEngine, ConflictResolver, SelfReflector, ProceduralMemoryManager) into one orchestrator with a status-row UI.

**Architecture:** New `modules/memory/daydream/` module with one orchestrator (`DayDreamEngine`) + four step modules (`prune`, `merge`, `refresh`, `reflect`). A new `DayDreamCoordinator` owns the idle timer and last-activity stamp (turn_service bumps it on user input). Manual trigger is a new Tauri command. Cycle completion is published as a new `RuntimeEventType::DaydreamCycle` family; frontend reduces into a `daydreamHistory` slice and renders in the Memory pane.

**Tech Stack:** Rust 2021, Tokio, Tauri 2, SQLite/LanceDB hybrid memory provider, React/TypeScript with Vite.

## Spec deviations (read first)

The spec at `docs/superpowers/specs/2026-05-08-a2-daydream-design.md` assumed two surfaces that turn out not to exist on vnext. Plan adjusts:

1. **No `daydream/report.rs` seed exists.** The spec's "Trim config (drop 2 fields)" wording came from a never-cherry-picked in-flight branch. All daydream code in this plan is greenfield (Task 1).
2. **`runtime/supervisor.rs` does not track user-input activity time.** Its "idle" refers to run-state (idle vs running). Plan creates a fresh `DayDreamCoordinator` (Task 7) that owns last-activity. `turn_service` bumps it on prompt entry (Task 9). Supervisor is untouched.
3. **`RuntimeEventPayload` enum doesn't exist.** Runtime payloads are JSON values keyed by `(RuntimeEventType, payload_family)`. Plan adds `RuntimeEventType::DaydreamCycle` family + payload_family constants (Task 8).

LOC and file-count deltas vs the spec's §7 table flow from these corrections; the externally-visible behavior (opt-in, idle@30min + manual, balanced default, status-row) is unchanged.

//! Cycle-outcome types reported back to the UI.

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

/// Per-step outcome counters. Each step appends one of these to the
/// report. A failed step still produces a `StepOutcome` with
/// `error: Some(_)` so the cycle is observable end-to-end.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct StepOutcome {
    /// Step name, lower-snake (`prune`, `merge`, `refresh`, `reflect`).
    pub step: String,
    /// Entries the step actually examined (≤ `max_entries_per_cycle`).
    pub examined: usize,
    /// Entries the step mutated (pruned / merged / refreshed / inserted).
    pub mutated: usize,
    /// Wall-clock milliseconds the step took.
    pub duration_ms: u64,
    /// `Some(reason)` if the step short-circuited or errored.
    pub error: Option<StepError>,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct StepError {
    /// Machine-readable kind (`token_cap`, `provider`, `llm`, `unexpected`).
    pub kind: String,
    /// Human-readable reason for the status row.
    pub message: String,
}

/// Per-cycle report. Emitted as a `RuntimeEventType::DaydreamCycle`
/// envelope on completion (success *or* failure).
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct DayDreamReport {
    /// Stable id; surfaced by the UI for the "expand cycle" modal.
    pub cycle_id: String,
    /// Triggered by `idle` or `manual`.
    pub trigger: String,
    /// Strategy that ran (mirrors the engine's config snapshot).
    pub strategy: String,
    /// Wall-clock start.
    pub started_at: DateTime<Utc>,
    /// Wall-clock end.
    pub finished_at: DateTime<Utc>,
    /// Per-step outcomes in execution order.
    pub steps: Vec<StepOutcome>,
}

impl DayDreamReport {
    /// `true` iff every step completed without an `error`.
    pub fn all_succeeded(&self) -> bool {
        self.steps.iter().all(|s| s.error.is_none())
    }
}

use crate::modules::memory::forgetting::{ForgettingConfig, ForgettingCurveEngine};
use crate::modules::memory::quality::QualityScorer;
use crate::modules::memory::SharedMemoryProvider;

use super::report::{StepError, StepOutcome};

/// Run the forgetting sweep and produce a `StepOutcome` for the daydream cycle.
pub async fn run(
    provider: &SharedMemoryProvider,
    scorer: &QualityScorer,
    forgetting: &ForgettingCurveEngine,
    max_entries: usize,
) -> StepOutcome {
    let started = std::time::Instant::now();
    let _ = max_entries; // forgetting sweep is internally bounded by provider size
    match forgetting.sweep(provider, scorer).await {
        Ok(r) => StepOutcome {
            step: "prune".into(),
            examined: r.examined,
            mutated: r.demoted + r.archived,
            duration_ms: started.elapsed().as_millis() as u64,
            error: None,

        Err(e) => StepOutcome {
            step: "prune".into(),
            examined: 0,
            mutated: 0,
            duration_ms: started.elapsed().as_millis() as u64,
            error: Some(StepError {
                kind: "provider".into(),
                message: format!("forgetting sweep failed: {e}"),
            }),
        },
    }
}

//! Merge step — embedding-similarity dedup with LLM fan-in.

use std::sync::Arc;

use crate::modules::memory::conflict::{ConflictDetector, ConflictResolver};
use crate::modules::memory::llm::UtilityLlm;
use crate::modules::memory::quality::QualityScorer;
use crate::modules::memory::{MemoryEntry, SharedMemoryProvider};

use super::report::{StepError, StepOutcome};

/// Approximate token budget for one Balanced cycle's merge step.
pub const BALANCED_MERGE_TOKEN_CAP: usize = 2000;
/// Approximate token budget for one Aggressive cycle's merge step.
pub const AGGRESSIVE_MERGE_TOKEN_CAP: usize = 5000;
/// Cosine similarity threshold to consider two entries duplicates.
pub const DUPLICATE_THRESHOLD: f32 = 0.92;

#[derive(Debug, Clone, Copy)]
pub struct MergeBudget {
    pub max_entries: usize,
    pub token_cap: usize,
}

/// Run the merge step. `llm` may be `None` for Conservative (caller skips
/// the step entirely) — callers in Balanced/Aggressive must provide one.
pub async fn run(
    provider: &SharedMemoryProvider,
    scorer: &QualityScorer,
    llm: Arc<dyn UtilityLlm>,
    budget: MergeBudget,
) -> StepOutcome {
    let started = std::time::Instant::now();

    // Pull a window of recent entries up to `max_entries`.
    let entries: Vec<MemoryEntry> = match provider.list_recent(budget.max_entries).await {
        Ok(v) => v,
        Err(e) => {
            return StepOutcome {
                step: "merge".into(),
                examined: 0,
                mutated: 0,
                duration_ms: started.elapsed().as_millis() as u64,
                error: Some(StepError {
                    kind: "provider".into(),
                    message: format!("list_recent failed: {e}"),
                }),
            };
        }
    };

    let pairs = find_duplicate_pairs(&entries, DUPLICATE_THRESHOLD);
    if pairs.is_empty() {
        return StepOutcome {
            step: "merge".into(),
            examined: entries.len(),
            mutated: 0,
            duration_ms: started.elapsed().as_millis() as u64,
            error: None,
        };
    }

    let detector = ConflictDetector::new();
    let resolver = ConflictResolver::new();
    let mut tokens_spent: usize = 0;
    let mut mutated: usize = 0;

    for (a_idx, b_idx) in pairs {
        let a = &entries[a_idx];
        let b = &entries[b_idx];
        // Estimate cost before calling the LLM. ~content length / 4 chars per token.
        let estimated = (a.content.len() + b.content.len()) / 4 + 200;
        if tokens_spent + estimated > budget.token_cap {
            return StepOutcome {
                step: "merge".into(),
                examined: entries.len(),
                mutated,
                duration_ms: started.elapsed().as_millis() as u64,
                error: Some(StepError {
                    kind: "token_cap".into(),
                    message: format!(
                        "merge short-circuited at {tokens_spent}/{} tokens",
                        budget.token_cap
                    ),
                }),
            };
        }
        // Detect the conflict, ask the LLM for a merged summary,
        // and apply via ConflictResolver.
        let conflict = match detector.detect_pair(a, b).await {
            Some(c) => c,
            None => continue,
        };
        let summary = match llm.summarize_pair(&a.content, &b.content).await {
            Ok(s) => s,
            Err(e) => {
                return StepOutcome {
                    step: "merge".into(),
                    examined: entries.len(),
                    mutated,
                    duration_ms: started.elapsed().as_millis() as u64,
                    error: Some(StepError {
                        kind: "llm".into(),
                        message: format!("summarize_pair failed: {e}"),
                    }),
                };
            }
        };
        tokens_spent += estimated;
        let new_quality = scorer.score(a, chrono::Utc::now()).max(scorer.score(b, chrono::Utc::now()));
        let resolution = resolver.resolve(&conflict, new_quality);
        if let Err(e) = resolver
            .apply_resolution(&conflict, &resolution, provider, Some(&summary))
            .await
        {
            return StepOutcome {
                step: "merge".into(),
                examined: entries.len(),
                mutated,
                duration_ms: started.elapsed().as_millis() as u64,
                error: Some(StepError {
                    kind: "provider".into(),
                    message: format!("apply_resolution failed: {e}"),
                }),
            };
        }
        mutated += 1;
    }

    StepOutcome {
        step: "merge".into(),
        examined: entries.len(),
        mutated,
        duration_ms: started.elapsed().as_millis() as u64,
        error: None,
    }
}

/// Pairs of indices in `entries` whose embeddings exceed `threshold`.
/// Linear (n²) scan; safe at `max_entries_per_cycle = 100` (≤ 5000 ops).
pub fn find_duplicate_pairs(entries: &[MemoryEntry], threshold: f32) -> Vec<(usize, usize)> {
    let mut out = Vec::new();
    for i in 0..entries.len() {
        let Some(ea) = entries[i].embedding.as_ref() else { continue };
        for j in (i + 1)..entries.len() {
            let Some(eb) = entries[j].embedding.as_ref() else { continue };
            if cosine(ea, eb) >= threshold {
                out.push((i, j));
            }
        }
    }
    out
}

fn cosine(a: &[f32], b: &[f32]) -> f32 {
    if a.len() != b.len() || a.is_empty() {
        return 0.0;
    }
    let mut dot = 0.0f32;
    let mut na = 0.0f32;
    let mut nb = 0.0f32;
    for k in 0..a.len() {
        dot += a[k] * b[k];
        na += a[k] * a[k];
        nb += b[k] * b[k];
    }
    if na == 0.0 || nb == 0.0 {
        return 0.0;
    }
    dot / (na.sqrt() * nb.sqrt())
}

#[cfg(test)]
mod tests {
    use super::*;
    use crate::modules::memory::MemoryEntry;

    #[test]
    fn cosine_returns_one_for_identical() {
        let a = vec![1.0, 0.0, 0.0];
        assert!((cosine(&a, &a) - 1.0).abs() < 1e-6);
    }

    #[test]
    fn cosine_returns_zero_for_orthogonal() {
        let a = vec![1.0, 0.0];
        let b = vec![0.0, 1.0];
        assert!(cosine(&a, &b).abs() < 1e-6);
    }

    #[test]
    fn finds_no_pairs_when_below_threshold() {
        let mut e1 = MemoryEntry::default();
        e1.key = "k1".into();
        e1.embedding = Some(vec![1.0, 0.0, 0.0]);
        let mut e2 = MemoryEntry::default();
        e2.key = "k2".into();
        e2.embedding = Some(vec![0.0, 1.0, 0.0]);
        assert!(find_duplicate_pairs(&[e1, e2], DUPLICATE_THRESHOLD).is_empty());
    }

    #[test]
    fn finds_pair_when_above_threshold() {
        let mut e1 = MemoryEntry::default();
        e1.key = "k1".into();
        e1.embedding = Some(vec![1.0, 0.0, 0.0]);
        let mut e2 = MemoryEntry::default();
        e2.key = "k2".into();

    }
}

//! Refresh step — re-embed stale entries (Aggressive-only).

use chrono::{Duration, Utc};
use std::sync::Arc;

use crate::modules::memory::embedding::EmbeddingService;
use crate::modules::memory::SharedMemoryProvider;

use super::report::{StepError, StepOutcome};

/// Entries whose `last_validated_at` is older than this are re-embedded.
pub const STALE_DAYS: i64 = 30;

pub async fn run(
    provider: &SharedMemoryProvider,
    embed: Arc<dyn EmbeddingService>,
    max_entries: usize,
) -> StepOutcome {
    let started = std::time::Instant::now();
    let cutoff = Utc::now() - Duration::days(STALE_DAYS);

    let entries = match provider.list_recent(max_entries).await {
        Ok(v) => v,
        Err(e) => {
            return StepOutcome {
                step: "refresh".into(),
                examined: 0,
                mutated: 0,
                duration_ms: started.elapsed().as_millis() as u64,
                error: Some(StepError {
                    kind: "provider".into(),
                    message: format!("list_recent failed: {e}"),
                }),
            };
        }
    };

    let mut mutated = 0;
    let mut examined = 0;
    for entry in entries.iter().filter(|e| e.last_validated_at.map_or(true, |t| t < cutoff)) {
        examined += 1;
        let new_vec = match embed.embed(&entry.content).await {
            Ok(v) => v,
            Err(e) => {
                return StepOutcome {
                    step: "refresh".into(),
                    examined,
                    mutated,
                    duration_ms: started.elapsed().as_millis() as u64,
                    error: Some(StepError {
                        kind: "llm".into(),
                        message: format!("embed failed: {e}"),
                    }),
                };
            }
        };
        if let Err(e) = provider
            .update_embedding(&entry.key, new_vec, Utc::now())
            .await
        {
            return StepOutcome {
                step: "refresh".into(),
                examined,
                mutated,
                duration_ms: started.elapsed().as_millis() as u64,
                error: Some(StepError {
                    kind: "provider".into(),
                    message: format!("update_embedding failed: {e}"),
                }),
            };
        }
        mutated += 1;
    }

    StepOutcome {
        step: "refresh".into(),
        examined,
        mutated,
        duration_ms: started.elapsed().as_millis() as u64,
        error: None,
    }
}

//! Reflect step — SelfReflector → ProceduralMemoryManager wiring.

use std::sync::Arc;

use crate::modules::memory::evolution::{
    procedural::ProceduralMemoryManager,
    reflector::{Insight, SelfReflector},
    trajectory::Trajectory,
};

use super::report::{StepError, StepOutcome};

/// Insights below this confidence are dropped before internalization.
pub const MIN_INSIGHT_CONFIDENCE: f64 = 0.7;

pub async fn run(
    reflector: &SelfReflector,
    procedural: &ProceduralMemoryManager,
    trajectories: Vec<Trajectory>,
) -> StepOutcome {
    let started = std::time::Instant::now();
    let examined = trajectories.len();

    let mut insights: Vec<Insight> = Vec::new();
    for t in &trajectories {
        if t.was_successful() {
            insights.extend(reflector.reflect_on_success(t));
        } else {
            insights.extend(reflector.reflect_on_failure(t));
        }
    }
    insights.retain(|i| i.confidence >= MIN_INSIGHT_CONFIDENCE);

    let mut mutated = 0;
    for insight in insights {
        match procedural.internalize_insight(&insight).await {
            Ok(_) => mutated += 1,
            Err(e) => {
                return StepOutcome {
                    step: "reflect".into(),
                    examined,
                    mutated,
                    duration_ms: started.elapsed().as_millis() as u64,
                    error: Some(StepError {
                        kind: "provider".into(),
                        message: format!("internalize_insight failed: {e}"),
                    }),
                };
            }
        }
    }

    StepOutcome {
        step: "reflect".into(),
        examined,
        mutated,
        duration_ms: started.elapsed().as_millis() as u64,
        error: None,
    }
}

//! DayDreamEngine — orchestrator that dispatches steps by strategy.

use std::sync::Arc;
use tokio::sync::Mutex;

use crate::modules::memory::embedding::EmbeddingService;
use crate::modules::memory::evolution::{
    procedural::ProceduralMemoryManager, reflector::SelfReflector, trajectory::Trajectory,
};
use crate::modules::memory::forgetting::ForgettingCurveEngine;
use crate::modules::memory::llm::UtilityLlm;
use crate::modules::memory::quality::QualityScorer;
use crate::modules::memory::SharedMemoryProvider;

use super::config::{ConsolidationStrategy, DayDreamConfig};
use super::merge::{MergeBudget, AGGRESSIVE_MERGE_TOKEN_CAP, BALANCED_MERGE_TOKEN_CAP};
use super::report::{DayDreamReport, StepError, StepOutcome};
use super::{merge, prune, reflect, refresh};

/// Source of trajectories the reflect step consumes.
/// Implementations live in the evolution module; this trait keeps the
/// engine testable with a stub.
#[async_trait::async_trait]
pub trait TrajectorySource: Send + Sync {
    async fn recent_trajectories(&self, max: usize) -> Result<Vec<Trajectory>, String>;
}

pub struct DayDreamEngine {
    provider: SharedMemoryProvider,
    scorer: Arc<QualityScorer>,
    forgetting: Arc<ForgettingCurveEngine>,
    llm: Arc<dyn UtilityLlm>,
    embed: Arc<dyn EmbeddingService>,
    reflector: Arc<SelfReflector>,
    procedural: Arc<ProceduralMemoryManager>,
    trajectories: Arc<dyn TrajectorySource>,
    config: DayDreamConfig,
    running: Mutex<bool>,
}

#[derive(Debug, thiserror::Error)]
pub enum CycleError {
    #[error("daydream is disabled")]
    Disabled,
    #[error("a cycle is already running")]
    AlreadyRunning,
}

impl DayDreamEngine {
    #[allow(clippy::too_many_arguments)]
    pub fn new(
        provider: SharedMemoryProvider,
        scorer: Arc<QualityScorer>,
        forgetting: Arc<ForgettingCurveEngine>,
        llm: Arc<dyn UtilityLlm>,
        embed: Arc<dyn EmbeddingService>,
        reflector: Arc<SelfReflector>,
        procedural: Arc<ProceduralMemoryManager>,
        trajectories: Arc<dyn TrajectorySource>,
        config: DayDreamConfig,
    ) -> Self {
        Self {
            provider,
            scorer,
            forgetting,
            llm,
            embed,
            reflector,
            procedural,
            trajectories,
            config,
            running: Mutex::new(false),
        }
    }

    pub fn config(&self) -> &DayDreamConfig {
        &self.config
    }

    /// Execute one cycle. `trigger` is "idle" or "manual"; surfaces in
    /// the emitted report and the status row.
    pub async fn run_cycle(&self, trigger: &str) -> Result<DayDreamReport, CycleError> {
        if !self.config.enabled {
            return Err(CycleError::Disabled);
        }
        {
            let mut guard = self.running.lock().await;
            if *guard {
                return Err(CycleError::AlreadyRunning);
            }
            *guard = true;
        }
        let report = self.run_cycle_inner(trigger).await;
        *self.running.lock().await = false;
        Ok(report)
    }

    async fn run_cycle_inner(&self, trigger: &str) -> DayDreamReport {
        let started_at = chrono::Utc::now();
        let cycle_id = uuid::Uuid::new_v4().to_string();
        let strategy = self.config.strategy;
        let max = self.config.max_entries_per_cycle;
        let mut steps: Vec<StepOutcome> = Vec::new();

        // Step 1 — Prune (always).
        steps.push(prune::run(&self.provider, &self.scorer, &self.forgetting, max).await);

        // Step 2 — Merge (Balanced + Aggressive).
        if matches!(strategy, ConsolidationStrategy::Balanced | ConsolidationStrategy::Aggressive) {
            let cap = if matches!(strategy, ConsolidationStrategy::Aggressive) {
                AGGRESSIVE_MERGE_TOKEN_CAP
            } else {
                BALANCED_MERGE_TOKEN_CAP
            };
            steps.push(
                merge::run(
                    &self.provider,
                    &self.scorer,
                    self.llm.clone(),
                    MergeBudget { max_entries: max, token_cap: cap },
                )
                .await,
            );
        }

        // Step 3 — Refresh (Aggressive only).
        if matches!(strategy, ConsolidationStrategy::Aggressive) {
            steps.push(refresh::run(&self.provider, self.embed.clone(), max).await);
        }

        // Step 4 — Reflect (Balanced + Aggressive).
        if matches!(strategy, ConsolidationStrategy::Balanced | ConsolidationStrategy::Aggressive) {
            let trajectories = match self.trajectories.recent_trajectories(max).await {
                Ok(v) => v,
                Err(e) => {
                    steps.push(StepOutcome {
                        step: "reflect".into(),
                        examined: 0,
                        mutated: 0,
                        duration_ms: 0,
                        error: Some(StepError {
                            kind: "provider".into(),
                            message: format!("trajectory source failed: {e}"),
                        }),
                    });
                    Vec::new()
                }
            };
            if !trajectories.is_empty() {
                steps.push(reflect::run(&self.reflector, &self.procedural, trajectories).await);
            }
        }

        DayDreamReport {
            cycle_id,
            trigger: trigger.into(),
            strategy: format!("{:?}", strategy).to_lowercase(),
            started_at,
            finished_at: chrono::Utc::now(),
            steps,
        }
    }
}

//! DayDreamCoordinator — owns the idle timer and last-activity stamp.

use std::sync::Arc;
use std::time::{Duration, Instant};
use tokio::sync::Mutex;

use super::engine::{CycleError, DayDreamEngine};
use super::report::DayDreamReport;

const POLL_INTERVAL: Duration = Duration::from_secs(60);

pub struct DayDreamCoordinator {
    engine: Arc<DayDreamEngine>,
    last_activity: Mutex<Instant>,
    /// `true` once a cycle has fired for the current idle window.
    /// Reset by `note_activity()`.
    fired_this_window: Mutex<bool>,
}

impl DayDreamCoordinator {
    pub fn new(engine: Arc<DayDreamEngine>) -> Self {
        Self {
            engine,
            last_activity: Mutex::new(Instant::now()),
            fired_this_window: Mutex::new(false),
        }
    }

    /// Called by `turn_service` on every prompt entry.
    pub async fn note_activity(&self) {
        *self.last_activity.lock().await = Instant::now();
        *self.fired_this_window.lock().await = false;
    }

    /// Manual trigger from the command. Bypasses the idle gate.
    pub async fn trigger_manual(&self) -> Result<DayDreamReport, CycleError> {
        self.engine.run_cycle("manual").await
    }

    /// Poll-tick: returns `Some(report)` if the idle threshold fired this tick.
    pub async fn maybe_fire(&self) -> Option<Result<DayDreamReport, CycleError>> {
        let cfg = self.engine.config();
        if !cfg.enabled {
            return None;
        }
        let elapsed = self.last_activity.lock().await.elapsed();
        let threshold = Duration::from_secs(cfg.idle_trigger_minutes * 60);
        if elapsed < threshold {
            return None;
        }
        let mut fired = self.fired_this_window.lock().await;
        if *fired {
            return None;
        }
        *fired = true;
        Some(self.engine.run_cycle("idle").await)
    }
}

/// Spawn the long-running poll loop. Cancel with the returned `JoinHandle`.
pub fn spawn_poll_loop<F>(
    coord: Arc<DayDreamCoordinator>,
    on_report: F,
) -> tokio::task::JoinHandle<()>
where
    F: Fn(DayDreamReport) + Send + 'static,
{
    tokio::spawn(async move {
        let mut ticker = tokio::time::interval(POLL_INTERVAL);
        loop {
            ticker.tick().await;
            if let Some(Ok(report)) = coord.maybe_fire().await {
                on_report(report);
            }
        }
    })
}

        let payload = serde_json::to_value(&report).unwrap_or(serde_json::Value::Null);
        let _ = crate::modules::runtime::runtime_event::dispatch(
            &app_handle,
            crate::modules::runtime::contracts::common::RuntimeEventType::DaydreamCycle,
